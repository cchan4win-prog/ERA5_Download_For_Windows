ERA5-reanalysis-complete下载器v2.0
Windows 10/11 64 位便携版

使用
完整解压 ZIP 到可写目录，再双击“ERA5-reanalysis-complete下载器v2.0.exe”。
无需安装 Python、Codex 或配置 CDS key；需联网且能访问 Google Cloud Storage。
点击“配置参数”打开图形窗口，用“＋添加”新站点或时间段，保存后点“开始”。打开程序不会自动下载。

五个按钮
开始：每次重新读取配置，按 tasks 和 periods 的书写顺序执行整个队列。
取消：结束当前所有下载和后续排队任务；保留已完成文件与续传缓存。
暂停：暂停整个队列；暂停后才能按“继续”。合并校验阶段暂停不可用。
继续：恢复暂停的队列，不重新读取配置。
配置参数：空闲时打开可视化设置；坐标按北上南下西左东右、站点在中间，时间和时区在右侧。
关闭窗口也会结束当前任务并保留断点。

配置重点
 time_zone: beijing 表示开始、结束和 hours 全部填北京时间（UTC+8）。
 time_zone: UTC 表示全部填 UTC。每个站点或每段 periods 都可覆盖全局设置。
 hours: [20,21,22,23,0,1,2,3,4,5,6,7,8] 表示每天20点到次日8点，含整点端点。
这只是固定时段筛选，不会自动判断日落日出。
 parallel_hours: 同时下载的小时文件数，1～16；workers: 总网络并发，1～64。
每个 tasks 项写 site、latitude、longitude 和 periods。
 periods 可写多个 start/end；只写日期时，开始取00:00，结束取23:00。
 config.multi.example.json 提供多地点多时段模板；null 经纬度须改成真实坐标。
示例不会自动运行；任务可设置 enabled:false 暂不执行。

时间、进度与目录
界面显示队列任务、总小时进度、并行文件进度、速度、累计用时和预计剩余时间。
暂停时间不计入已用时，断点记录保存在 data 内 timing.json 与 .queue_records。
累计队列用时包含下载、准备和合并校验；中断重启后从最近记录继续累计。
预计剩余时间按当前实测每小时耗时估算；开始时显示“估算中”，网络速度或后续区域大小变化会使估计变化。
合并和校验耗时无法可靠预估，合并时单独显示阶段，不承诺具体完成时间。
新任务目录为 data/site_开始日期_结束日期；同名但坐标/参量/小时等不同，加短后缀防止混用。
旧版本已有任务会复用原目录，避免重新下载；不会擅自重命名已有数据。
每个时间段下载齐全后自动生成该目录 merged 里的单个 NC，再进入下一个时间段。
小时文件与 NC 时间坐标仍按 UTC 存储；137 个模式层不等于固定等压层或真实高度。

错误与分享
遇到超时、断网、服务器临时错误或限流，程序会自动重连并续传。快速重试后，重试间隔从 15 秒逐步延长至 120 秒。等待期间仍可暂停或取消。配置错误和永久性 HTTP 错误会停止队列并显示错误；修正后再次点击“开始”可复用已完成文件。
日志在 .gui_sessions，队列累计记录在 .queue_records；包内不含个人数据或历史日志。
分享整个 ZIP，不要只复制一个 EXE；勿删除 runtime、.runtime_deps 和 Python 脚本。
安装目录必须可写；不要直接在压缩软件里运行或放在需要管理员权限的目录。
窗口使用 Windows 自带 .NET Framework；精简系统若移除了它，需要恢复 .NET Framework 4.8。
更多说明见“详细说明.md”；第三方许可见“第三方组件说明.txt”。

真实高度文件
每段下载合并后，自动在合并文件旁生成 *_real_height.nc。
包含原气象参量以及p_full气压、z_full位势高度、h_full几何高度。
几何高度为相对平均海平面的球形地球近似；每时刻每层对应一个实际高度，不重采样为固定高度间隔。
配置窗口中“生成真实高度文件”会自动补齐完整137层T/Q、地面气压和地表位势。
保存配置前检查经纬度、时间及小时；取消配置窗口不会改动原文件。
